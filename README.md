## 📌 Overview

This project serves as the frontend client for the **Kim Truong Phuc Equipment Management System**. It enables plant managers, engineers, and technicians to monitor equipment status, schedule preventative maintenance, track operational histories, and reduce facility downtime through a clean and intuitive dashboard.

---

## ✨ Key Features

- 📊 **Interactive Dashboard:** Real-time visibility into overall equipment health, active machinery, and critical alerts.
- 🛠️ **Equipment Lifecycle Tracking:** Detailed records of machine specs, operation status (Active, Maintenance, Retired), and location.
- 📅 **Maintenance Scheduling:** Assign inspection and repair tickets to field technicians.
- 🔐 **Role-Based Views (RBAC):** Customized interface and permissions based on user roles (Admin, Manager, Technician).
- 📱 **Fully Responsive:** Optimized for desktop workstations, tablets, and mobile devices in the field.

---

## 🛠️ Tech Stack

- **Core:** React.js
- **Styling:** Tailwind CSS / CSS Modules
- **State Management & Data Fetching:** React Hooks, Axios
- **Routing:** React Router DOM
- **Icons & UI Assets:** Lucide React / React Icons
